オーガキングダム GitHub Pages 試作版

【内容】
index.html        トップページ
episode1.html     第1話の漫画ビューア
assets/style.css  デザイン
pages/            漫画画像

【PCで確認する方法】
1. このZIPを展開します。
2. index.html をダブルクリックします。
3. ブラウザでトップページが開きます。
4. 「第1話を読む」を押すと漫画を読めます。

【GitHub Pagesへ公開する場合】
フォルダの中身をGitHubリポジトリの一番上にアップロードしてください。
その後、GitHub Pagesを有効にします。

※公開前に、画像内を含めて個人情報が入っていないか確認してください。
